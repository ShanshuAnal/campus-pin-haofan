# LLM 辅助开发记录

本文档用于记录“校园拼好饭系统”开发过程中由 LLM 辅助完成的需求梳理、设计建议、代码生成、问题排查和验证情况。

## 记录原则

- 记录 LLM 参与的重要修改，不记录无意义的临时问答。
- 每次记录应说明修改目标、涉及文件、主要内容和验证方式。
- 对 LLM 生成的代码或方案必须由开发者审查后再采用。
- 涉及金额计算、状态流转、权限校验和数据一致性的修改，应重点记录验证情况。

## 记录模板

```text
日期：
参与方式：
目标：
涉及文件：
主要改动：
验证方式：
结果：
后续事项：
```
