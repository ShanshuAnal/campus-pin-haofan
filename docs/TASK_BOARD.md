## 使用规则

- 开始任务前将状态改为 `DOING`。
- 完成并验证后将状态改为 `DONE`。
- 无法继续时将状态改为 `BLOCKED`，并在备注中说明原因。
- 不删除历史任务；废弃任务在备注中说明。
