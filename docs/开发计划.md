# 开发计划

本文档记录“校园拼好饭系统”的阶段性开发计划。项目采用前后端分离结构，先完成业务建模和基础工程，再逐步实现核心流程。

## 阶段一：项目初始化

目标：

- 明确项目定位、技术栈和开发约束；
- 建立基础文档；
- 确定前后端目录结构；
- 确定数据库脚本管理方式。

任务：

- 创建 `AGENTS.md`；
- 创建 `README.md`；
- 创建 `docs/LLM辅助开发记录.md`；
- 创建 `docs/开发计划.md`；
- 创建 `sql/README.md`。

验收标准：

- 文档覆盖项目定位、技术栈、目录结构和核心业务流程；
- 明确金额计算使用 `BigDecimal`；
- 明确状态流转由后端校验；
- 明确不主动引入未要求的复杂中间件。

## 阶段二：需求与模型设计

目标：

- 梳理核心业务对象；
- 明确状态枚举和状态流转规则；
- 设计数据库表结构；
- 明确接口边界。

建议业务对象：

- 用户；
- 拼单；
- 拼单参与者；
- 餐品条目；
- 付款记录；
- 取餐记录；
- 操作日志。

重点事项：

- 金额字段统一使用 `BigDecimal` 和数据库 `DECIMAL` 类型；
- 状态流转集中维护；
- 付款确认和取餐确认需要权限校验；
- 设计金额分摊规则和尾差处理方式。

## 阶段三：后端工程骨架

目标：

- 创建 Spring Boot 3 后端工程；
- 配置 Java 21、MyBatis 3 和 MySQL 8；
- 建立统一响应、异常处理、参数校验和基础分层结构。

任务：

- 创建 `backend/` 工程；
- 配置 Maven 依赖；
- 建立基础包结构；
- 配置数据库连接；
- 建立通用响应和异常处理；
- 添加基础健康检查接口。

验收标准：

- 后端工程可启动；
- 基础接口可访问；
- 数据库连接配置清晰；
- 分层结构符合 `AGENTS.md` 约定。

## 阶段四：前端工程骨架

目标：

- 创建 Vue3 + Vite + TypeScript 前端工程；
- 接入 Element Plus、Pinia 和 Axios；
- 建立路由、布局、API、状态管理和类型目录。

任务：

- 创建 `frontend/` 工程；
- 配置 Vite 和 TypeScript；
- 配置 Element Plus；
- 配置 Pinia；
- 配置 Axios 实例；
- 建立基础页面和路由。

验收标准：

- 前端工程可启动；
- 基础页面可访问；
- API 请求封装集中管理；
- 目录结构符合 `AGENTS.md` 约定。

## 阶段五：核心业务实现

目标：

- 实现用户、拼单、参与者、金额分摊、付款标记和取餐协同核心流程。

建议顺序：

1. 用户基础能力；
2. 拼单创建和列表；
3. 加入拼单和参与者管理；
4. 锁单和状态流转；
5. 金额分摊；
6. 付款标记与确认；
7. 下单与取餐协同；
8. 订单完成和历史记录。

重点测试：

- 金额分摊总额一致；
- 优惠和费用分摊正确；
- 尾差处理正确；
- 非法状态流转被拒绝；
- 无权限操作被拒绝。

## 阶段六：联调与完善

目标：

- 完成前后端联调；
- 完善错误提示、边界场景和基础体验；
- 补充测试和部署说明。

任务：

- 前后端接口联调；
- 完善统一错误处理；
- 补充数据库初始化脚本；
- 补充运行说明；
- 根据实际需要评估是否引入 Redis 或 RocketMQ。

验收标准：

- 核心流程可完整跑通；
- 关键业务约束有后端校验；
- 金额计算有测试覆盖；
- README 包含可执行的启动说明。
