# 校园拼好饭系统

校园拼好饭系统是一个面向高校学生的拼单、凑单、金额分摊、付款标记与取餐协同系统。项目采用前后端分离结构，后端提供业务 API，前端提供学生端交互界面。

## 项目定位

本系统用于支持校园内常见的多人拼饭场景：

- 学生发起拼单或加入拼单；
- 拼单发起人统一下单；
- 系统按规则分摊餐品、配送费、包装费和优惠金额；
- 参与者标记付款，发起人确认付款；
- 拼单成员协同完成取餐与订单完成确认。

## 技术栈

后端：

- Spring Boot 3
- Java 21
- MyBatis 3
- MySQL 8
- Maven

前端：

- Vue 3
- Vite
- TypeScript
- Element Plus
- Pinia
- Axios

可选：

- Redis：仅在缓存、限流、分布式锁或短期状态管理有明确收益时使用。
- RocketMQ：仅在异步通知、削峰或状态事件有明确收益时使用。

## 核心功能规划

- 用户注册、登录与身份识别；
- 拼单创建、编辑、取消；
- 加入拼单、退出拼单、修改餐品；
- 拼单锁定、下单、取餐、完成；
- 金额分摊与尾差处理；
- 付款标记与发起人确认；
- 取餐人指定、取餐状态维护；
- 拼单列表、详情和个人参与记录。

## 关键业务约束

- 金额计算必须使用 `BigDecimal`。
- 状态流转必须由后端校验。
- 不允许仅依赖前端按钮控制业务状态。
- 不主动引入未要求的复杂中间件。
- 简单同步业务优先使用清晰的单体后端实现。
