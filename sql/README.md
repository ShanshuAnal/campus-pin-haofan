# SQL 目录说明

本目录用于存放“校园拼好饭系统”的数据库脚本、初始化数据和数据库变更说明。

## 技术约束

- 数据库版本：MySQL 8。
- 金额字段应使用 `DECIMAL` 类型，不使用浮点类型。
- 时间字段应明确创建时间、更新时间和必要的业务时间。
- 状态字段应与后端枚举保持一致。

## 建议文件组织

```text
sql/
├── README.md
├── schema.sql
├── data.sql
└── migrations/
```

说明：

- `schema.sql`：数据库表结构初始化脚本。
- `data.sql`：本地开发或演示用初始化数据。
- `migrations/`：后续数据库变更脚本。

## 建表设计注意事项

- 用户、拼单、参与者、餐品条目、付款记录、取餐记录应优先建模清楚。
- 金额字段建议使用 `DECIMAL(10,2)`，如后续存在更高精度要求再调整。
- 重要表应包含 `created_at` 和 `updated_at`。
- 软删除字段是否需要引入，应根据业务查询和审计要求决定。
- 拼单状态、付款状态、取餐状态应与后端状态枚举保持同步。

## SQL 编写要求

- 脚本应可重复阅读和审查。
- 表名、字段名使用清晰一致的命名。
- 不在 SQL 中隐藏复杂业务规则。
- 复杂金额计算应由后端服务使用 `BigDecimal` 完成，SQL 只负责存储和必要查询。
